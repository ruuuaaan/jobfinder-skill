# 行政区划离线快照

获取：2026-09-21；名单版本：2024（上游README声明），非2026现行完整性保证。
上游：https://github.com/caijf/lcn （MIT，caijf）；原始数据：https://raw.githubusercontent.com/caijf/lcn/refs/heads/master/data/data.json 。
上游引用民政部：https://www.mca.gov.cn/mzsj/xzqh/2025/202401xzqh.html 。本次该官方页面工具访问超时，采用保留许可证的上游转录数据，未宣称逐项与官方当前名单校对。
用途仅行政地名标准化，不是企业名录、招聘覆盖或国别证明。代码显式排除71/81/82编码，保留歧义地名UNKNOWN。新增/改名城市需要更新可追溯快照并测试，不能猜测。
