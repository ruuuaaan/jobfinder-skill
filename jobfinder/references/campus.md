# 高校就业网渠道（campus_job）

面向应届生与高校毕业生的岗位信息来源。**独立成一个阶段**（`campus`），排在招聘平台之后、本地宝网站之前：它比本地宝更垂直、岗位更真，但覆盖面明显小于主流招聘平台。

## 一、三层入口

| 层级 | 入口 | 说明 | 实测状态（2026-10-31） |
|---|---|---|---|
| 国家级 | `https://www.ncss.cn/student/jobs/index.html` | 国家大学生就业服务平台（教育部学生服务与素质发展中心）。今日职位 114 万+，覆盖全国 | ✅ 列表页可静态读取（岗位名/薪资/地点/学历/公司/详情链接/发布时间）；**搜索是前端 AJAX，URL 不变**，须浏览器操作搜索框 |
| 省市级 | `https://www.firstjob.shec.edu.cn/`（上海24365大学生就业服务平台，上海市学生事务中心/市教委） | 有「用人单位服务交流平台」「长三角招聘专区」；首页有 2027 届信息登记弹窗，需先关闭 | ⚠️ 首页 JS 渲染，静态读取只得站名；须浏览器打开 |
| 校级 | 各高校就业网，两种形态见下 | 岗位最全、更新最快，但一校一站 | ✅ 才立方系统可静态读详情 |

### 校级的两种形态

**A. 才立方系统（最常见，`*.91wllm.cn`）**

```
https://<学校缩写>.91wllm.cn/job/view/id/<职位ID>/from_type/4/from_id/<来源ID>
```

- 详情页可**静态读取**：职位名、薪资区间、工作地点、学历、专业要求、职位详情全文、单位性质/行业/规模、主办单位、联系方式（部分需登录）。
- 实例：`scuec.91wllm.cn`（中南民族大学）等。
- 列表页路径通常为 `/job/list` 或站内搜索，同样存在 AJAX 情况，先用浏览器确认。

**B. 学校自建站（域名各异）**

- `career.bnu.edu.cn`（北师大，路径 `/f/recruitmentinfo/show?recruitmentId=...`）
- `job.cqupt.edu.cn`（重邮，`/portal/home/recruitment-detail.html?id=...`）
- 上海交大通过「上海交通大学人才招聘网」发布，常被应届生求职网（`yingjiesheng.com`）转载。

> 校名与域名不一一对应，**不要凭校名猜域名**：先用 `domain_search` 或 `WebSearch` 找到该校就业网的真实入口，再读。

## 二、执行要点

1. **一条任务 = 一次站内检索或一个列表页**，与其它渠道共用渠道配额（默认 5 次）。配额用完即止，剩余任务记 `budget_exhausted`。
2. **发布方不是雇主**。就业网转载的岗位，雇主以职位详情里的「单位名称」为准；学校只是发布渠道，不能把学校当公司写进汇总表。
3. **同一岗位会跨校重复转载**。实测南孚集团「财务管理培训生(财务BP)」同时出现在中南民族大学、北师大、重邮三站——入库必须去重，去重键用「公司＋岗位名＋工作地点」，不要用 URL（URL 各校不同）。
4. **岗位性质要按原文核**。就业网并非只有校招：
   - 「财务管理培训生(财务BP)」这类是校招管培岗，属财务BP，但要求应届；
   - 「科研财务助理」「财务处职员」是高校教辅/行政岗，**不是**财务BP，按职责排除；
   - 也会混入社招岗（部分企业把社招也贴到就业网）。
5. **应届资格不能替用户假设**。用户未声明应届身份时，校招岗照常收录，但要在备注写清「限应届/2027届」等原文条件；不得因为「用户可能不是应届」就静默剔除，也不得假设用户符合。
6. **薪资多为区间或年薪**（如「14w-16w」），按原文记录，不换算、不推测。

## 三、检索方式与坑

| 情况 | 做法 |
|---|---|
| 列表页可静态读（ncss.cn 列表） | 直接 `WebFetch`，一次能拿到 10–20 条带链接的卡片 |
| 搜索框是 AJAX（ncss.cn 搜索、firstjob 首页） | 用宿主可见浏览器：输入关键词 → 回车 → 读渲染后的 DOM 或截图；**URL 不会变**，不能靠构造 `?keyword=` 翻页（实测无效，仍返回全量） |
| 需要登录才能看联系方式 | 只取公开字段（岗位名/公司/地点/学历/薪资/职责），联系方式留空并备注「需登录」 |
| 站点 WAF 拦截或 404 | 记 `blocked` 并附失败证据，**不要**记成「零岗位」 |

## 四、覆盖边界（写报告时必须说明）

- 高校就业网以**校招/应届**为主。查「财务BP」这类通常要求 3–5 年经验的岗位，命中率明显低于招聘平台，零结果属正常，不代表市场上没有。
- 一校一站、域名分散，**无法穷举**。一轮只覆盖被检索到的那几所学校，报告里要写清「本轮实际读取了哪些学校站点」，不能笼统说「高校渠道已查完」。
- 校内岗位常年挂着不撤，**发布 ≠ 仍在招**。所有条目 `open_status` 记 `UNKNOWN`，进 REVIEW。
- 省级平台（如上海24365）多为活动/专区聚合，岗位列表需登录或跳转企业系统，**能读到多少算多少**，不追求完整。
